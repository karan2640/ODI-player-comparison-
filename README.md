# Cricket Player Statistics Dashboard

This is an interactive Streamlit app for displaying and comparing cricket player statistics, with features to analyze players' performances in ODIs (One Day Internationals). The app provides an overview of player statistics, visualizations, and comparison tools to help users analyze and compare cricket players based on their runs, strike rate, centuries, and averages.

## Features
- **Cricket Player Stats Overview**: Displays basic statistics for all players, such as total matches, runs, batting average, strike rate, centuries, fifties, highest score, and ICC ranking.
- **Top 5 Players by Runs**: Shows the top 5 players based on the total runs scored.
- **Player Performance Over Time**: Graphically represents how each player's performance (total runs) has evolved over time.
- **Strike Rate vs Runs**: A scatter plot showing the relationship between runs scored and strike rate for all players.
- **Compare Multiple Metrics for Players**: Allows the user to compare players based on various metrics such as runs, average, and strike rate.
- **Centuries and Fifties Pie Chart**: Displays the percentage distribution of centuries and fifties for the selected player.
- **Comparison of Players Based on Runs**: Bar chart to compare the runs scored by players.
- **Player Performance Summary**: Detailed statistics for the selected player, including runs, batting average, strike rate, centuries, and fifties.
